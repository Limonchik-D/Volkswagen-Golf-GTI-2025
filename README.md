# Volkswagen Golf GTI 2025 Showcase

## Asset Setup Instructions

To complete the setup, you need to copy the assets from your Downloads folder (`C:\Users\Volkswagen Golf GTI 2025_ фото, характеристики - Auto24_files`) into the `public/assets/` directory of this project.

1. **Create the directory**: 
   Inside this project's `public` folder, create a new folder named `assets`.

2. **Copy the following files into `public/assets/`**:
   - `volkswagen_golf_gti_2025.glb` (The 3D model)
   - `эстетика.mp4` (Used in the interior transition video)
   - `golf-gti-brochure.pdf` (Linked in the footer CTA)

3. **Run the project**:
   ```bash
   npm run dev
   ```

## Tech Stack
- React + Vite
- React Three Fiber & Drei (3D Rendering)
- GSAP & ScrollTrigger (Animation & Scrollytelling)
- Lenis (Smooth Scrolling)
- Tailwind CSS (Styling)
